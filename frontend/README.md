# Proyecto Tenis de Mesa

Una aplicación web para la gestión de torneos de tenis de mesa, incluyendo registro de jugadores, creación de torneos, sistema de rankings, noticias locales y contenido educativo.

## Características

- Registro e inscripción de jugadores
- Creación y gestión de torneos
- Sistema de rankings actualizado con resultados
- Sección de noticias locales
- Apartado educativo dividido en niveles: bajo, medio y alto
- Diseño con colores predominantes rojo y negro
- Estilos con Bootstrap

## Instalación

1. Instala las dependencias:
   ```bash
   npm install
   ```

2. Ejecuta el servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Abre tu navegador en `http://localhost:5173`

## Construcción

Para construir la aplicación para producción:
```bash
npm run build
```
